
# 🚰 Programa para controle de nível de água em um reservatório
  
- 🖥️ Sistema simples de monitoramento de um reservatório de água.
- 📊 O sitema opera com cinco níveis de água que vai do menor nível ao nível máximo do reservatório. Cada nível possuí uma mensagem de alerta e uma cor correspondente, conforme a progressão de risco:
  - Nível	    Situação	            Cor
    Nível 1	    Muito baixo (crítico)	Vermelho
    Nível 2	    Baixo	                Amarelo
    Nível 3 	Médio	                Verde
    Nível 4	    Alto	                Ciano
    Nível 5	    Muito alto (alerta)	    Azul
 
- Como utilizar:
    - O próprio sistema informa o grau de risco conforme a consulta que é realizada, basta teclar "enter".
